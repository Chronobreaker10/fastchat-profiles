# FastChat Profiles

Микросервис пользовательских профилей для мессенджера **FastChat**. Разработан на **FastAPI**, **SQLAlchemy** и **PostgreSQL**. Проверка прав доступа реализована через **JWT** токены, используется асимметричный алгоритм **RS256**, информация о пользователях хранится в базе данных **PostgreSQL**. **Redis** используется для кэширования профилей.

## 🚀 Возможности (Use Cases)

- **JWT-аутентификация**:
  - Проверка прав доступа и получение данных пользователя из Access токена
- **Управление профилем**:
  - Создание нового профиля при регистрации
  - Просмотр профилей пользователей
  - Редактирование информации о себе

## ✨ Запуск проекта

Генерация пары ключей: 
```bash
openssl genrsa -out private.pem 2048
openssl rsa -in private.pem -pubout -out public.pem

```

Создание папки для хранения ключей:
 ``` bash  
mkdir secret_keys
mv ./private.pem ./secret_keys/
mv ./public.pem ./secret_keys/
```

Создание docker-сети:
```bash
docker network create fastchat-net
 ```

Запуск Docker контейнеров
```bash
just docker-up
 ```
